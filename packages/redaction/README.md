# Redacción

> **Pendiente:** Fase 1, semana 7. Esta carpeta se reserva para mantener la estructura del monorepo.

Redacción de headers, parámetros y campos sensibles; detector de secretos (JWT, claves de API, claves privadas).

Especificación: `docs/especificacion-qatlas.md`, sección 3.8.

Cuando se implemente, este paquete necesita `package.json`, `tsconfig.json`, tests unitarios y,
si corresponde, su test en `security-tests/`.
