# App de prueba

> **Pendiente:** Fase 1, semana 4. Esta carpeta se reserva para mantener la estructura del monorepo.

Sitio con errores y trampas plantadas (404, error de JS, botón sin label, botón "Eliminar", redirecciones a otros dominios, WebSocket externo, service worker, script de "analítica", JWT en consola) para probar el escáner sin depender de sitios reales.

Especificación: `docs/especificacion-qatlas.md`, sección 11.

Cuando se implemente, este paquete necesita `package.json`, `tsconfig.json`, tests unitarios y,
si corresponde, su test en `security-tests/`.
